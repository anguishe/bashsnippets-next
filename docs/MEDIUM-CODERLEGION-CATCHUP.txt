PART 1 - MEDIUM: ONE SITTING, ~60 MIN, THEN NEVER AGAIN
================================================================================
Do this once and Medium matches dev.to: every post scheduled, nothing recurring.

WHAT CHANGED: DO NOT USE IMPORT ANY MORE
  The old recipe imported the canonical URL (to get the canonical link), then
  select-all-replaced the imported body with the .html because the import
  mangles code blocks. Two steps fighting each other - and the import step is
  what broke post #01. Medium has a manual canonical field, so the import is
  unnecessary. New story, paste, set canonical, schedule. One pass.

FIRST, FIX POST #01 (it is live and wrong) - 5 min
  1. Open your published Medium copy of "For Months My Dev Server Came Up on
     3001". It went up as raw markdown on 9/16 - "##" and backticks are visible
     as text and the quotes are curled.
  2. Edit -> click in the body -> Ctrl+A.
  3. Open queue/01-open-ports-linux-medium.html in a browser, Ctrl+A, Ctrl+C.
  4. Back in Medium: Ctrl+V.
  5. Delete the leftover "# For Months..." line if it survived.
  6. Check Advanced settings still has the canonical (it was imported, so it
     should). If not, add it - see step 5 below.
  7. Save and publish.

THEN, FOR EACH OF POSTS 02 THROUGH 14 - about 4 min each
  1. https://medium.com/new-story        <- blank story. NO import.
  2. Double-click queue/NN-<slug>-medium.html so it opens in a browser.
     Click in the page, Ctrl+A, Ctrl+C.
  3. Back in the Medium draft: click in the body, Ctrl+V.
     PASTE THE .html, NEVER THE .md. Medium renders markdown literally and then
     curls 'quotes' and turns --flag into an em-dash, breaking every command.
  4. TYPE the title into Medium's title box by hand. No "# ".
     The .html has no title in it. Pasting a markdown heading into that box is
     what produced both previously broken titles.
  5. *** SET THE CANONICAL. THIS IS THE STEP THAT CAN BE FORGOTTEN. ***
     Story settings (the "..." menu) -> Advanced settings ->
     "This story was originally published elsewhere" ->
     paste the canonical_url from the table below -> Save canonical link.
     Without it, Medium's copy competes with bashsnippets.xyz instead of
     feeding it. This is the only step that can do active harm if skipped.
  6. Add the 5 tags from the table below.
  7. Schedule for later -> the date below, 08:00. Medium publishes within five
     minutes of the time you set, in your local timezone.
  8. VERIFY BEFORE MOVING ON: one code block still shows straight 'quotes' and
     --flags, and the canonical is saved. Then paste the Medium URL into the
     Done column in queue/README.md.
